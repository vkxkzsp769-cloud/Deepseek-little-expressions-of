# Deepseek little expressions of · 悬浮表情球

> dsh Web 界面上的**悬浮表情球插件**：会盯着鼠标看、可以拖着满屏跑、内置 32 种表情，
> 位置和设置自动记住；跑任务时会「忙起来」，还会用聊天气泡把情绪说出来。
> 表情引擎来自 [Grok Ball](https://github.com/tycoding/grok-ball)（MIT）。

仓库：<https://github.com/vkxkzsp769-cloud/Deepseek-little-expressions-of>

```sh
dsh plugin --profile web add git+https://github.com/vkxkzsp769-cloud/Deepseek-little-expressions-of.git
```

一个会「看」你的圆球，浮在整个 dsh Web 界面上方（不遮挡操作，只有球本身接收鼠标事件）。

## ✨ 特性

- **悬浮 + 可拖动**：按住球拖动到任意位置，松手即记住；窗口尺寸变化后自动回到可视区域内。
- **AI 大脑（默认开启）**：每轮对话结束后，把「用户最后一句 + 助手最后一段」交给模型判断情绪，球据此换表情——用户激动就跟着开心，用户说「你怎么这么蠢」就切到 `17 慌张` / `12 失落`。每轮只发一次极短分类调用（约 0.3k 输入 / 0.2k 输出 token）。
- **跑任务时会「忙起来」**：dsh 会话一进入运行状态，球切到 `30 思考中`，并且**每 5–11 秒来一次小动作**——换一个工作表情（`32 处理中` / `40 检索资料` / `31 接收任务` / `37 复述回忆`）、偶尔惊讶或专注一下（`13` / `16`），外加自旋甩彩带、弹跳、撒花。任务结束回到大脑判断的心情或你手选的表情。不想要就面板里切「安静工作」。
- **拖动跟手**：拖动期间直接写 DOM 并用 `requestAnimationFrame` 合并，不再每个 pointermove 触发一次 React 渲染（实测 60 次移动事件只产生 9 次样式写入）。
- **32 种表情 / 随时切换**：生命周期、情绪反应、代理工作状态三组，长按（触屏）或右键（鼠标）球打开面板即可切换；数字键 `1`–`9` 快速切换前 9 个表情。
- **手机友好**：长按球打开面板（球本身禁用了文字选择与系统长按菜单，不会弹「复制」）；面板里有 5 个位置按钮，一键把球送到四角或屏幕正中，不必精确拖动。
- **眼神跟随鼠标**：眼球以球心为原点实时追踪光标；指针离开窗口后自动回到正面。
- **点击有反应**：单击球会撒花 + 自旋 + 弹跳。
- **会自动犯困**：默认 1 分钟无操作转「待机放空」，3 分钟进入「睡眠」（头顶 zzz）；可在面板里关掉，改成一直保持当前表情。
- **设置自动记忆**：位置、尺寸、主题、表情、开关全部自动保存（位置存浏览器，配置同时写入 `$DSH_HOME/float-ball.json`）。
- **不打扰操作**：叠加在界面最上层但只有球自己接收鼠标事件；提示气泡 6 秒后自动消失。
- **零外部资源**：引擎（SVG 实时驱动）与样式全部内联，不请求任何字体 / 图片 / CDN。

| 操作 | 效果 |

| 键盘 `Delete`（球聚焦时） | 回到右下角默认位置 |

### 聊天气泡：让它把情绪说出来（`src/client/18-speech.js`）

球旁边会浮出一个气泡，用符合当前心情的语气说一句话。

- **默认让模型写**：把「当前心情 + 判断原因 + 最近一轮对话 + 最近说过的话」发给
  `/float-ball-rpc/float-ball/say`，要求 8–24 字的中文口语短句，第一人称，不带 emoji；
- **本地台词库兜底**：模型没配好 / 调用失败 / 用户选了「只用本地」时，从按情绪分组的
  台词库里取（开心、失落、慌张、害羞、专注、出错、等待……共 18 组 + 通用组，每组 4-5 句、都带性格），**零 token**；
- **气泡与屏幕上此刻的表情一致**：说之前把当前表情快照下来，避免「表情已经变成松一口气、
  嘴里却在说工作台词」；
- **不像客服，也不复读**：三层防重复——① 每次随机给一段「人格碎片」（粘人 / 嘴硬心软 / 戏多 / 困倦…），同一心情也能说出不同调子；
  ② 最近 6 句说过的话回传给模型，明确禁止重复开头、句式与比喻；③ 客户端还有一道闸门，拦下
  「客服道歉腔」（`抱歉，我…`）、模板句（`再看一遍`）、太短太干的句子，以及模型把提示词抄出来的情况——
  命中就自动重说一次，仍不行才回退本地台词。
- **气泡跟着情绪变**：暖色（开心/满意/害羞）、冷灰（失落/疲惫/无奈）、警示红（慌张/出错）、
  安静蓝灰（思考/专注/检索）四种色调，一眼看出它现在什么状态；
- **看得完，不抢话**：气泡停留时长 = 打字时间（约 0.6 秒 + 每字 42ms）+ 阅读时间（每字 65ms，
  最少 2.6 秒、最多 9 秒）；一句话通常停留 **4–8 秒**。**点一下不是收起，而是「我还没看完」——
  再多留 5 秒，可以连点**。
- **新话排队，不顶掉正在显示的那条**：当它在说话时又来了新台词（比如任务结束的心情、
  下一拍小动作），新话进入队列（最多 2 条），等当前这句读完再上。所以不会再出现
  「刚看一半就被换掉」。
- **节流**：两次说话至少间隔 20 秒，且不会连续说同一句；逐字打出，像在说话而不是弹窗；
- **小尖尖一直指着球**：气泡位置每帧重算——横向居中在球上（贴边时夹进视口）、
  上方放不下就翻到球下方，尖尖的横向位置 = 球心 − 气泡左边（夹在圆角内），纵向跟着翻面；
  所以球被拖到哪儿、窗口怎么缩，尖尖都对着球；
- **触发点**：心情变化时（大脑判断 / 任务结束的收尾）、点球互动时；跑任务期间随小动作自然说几句。

优化前后对比（同一场景连打 8 次，输入都是「你怎么这么蠢，这么简单的 bug 都修不好」）：

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 以「我」开头 | 7 / 8 | 1 / 8 |
| 出现模板句「再看一遍」 | 4 / 8 | 0 / 8 |
| 「抱歉 / 对不起」客服腔 | 大量 | 0 |
| 有具体意象（红字/日志/蹲墙角/尾巴） | 几乎没有 | 7 / 8 |

真实模型实测（同一套 prompt、只改心情）：

| 心情 | 它说的话 |
| --- | --- |
| 被骂蠢 → `12 失落` | 「那个……我盯着报错看了好久，还是没改对……」 |
| 等你输入 → `35` | 「我趴在角角这儿～等你敲下一行字呀」 |
| 又报错 → `34 出错` | 「唔……又红了，我再悄悄看一眼日志哈……」 |
| 被你催 → `17 慌张` | 「别急别急，我手都快抖了，马上就好～」 |
| 被夸 → `14 害羞` | 「被你一夸我都不好意思啦～」 |
| 一次跑通 → `10 开心` | 「嘿嘿一次就过啦，我是不是有点厉害～」 |

成本与心情判断同一量级（一句话几十个 token），而且和心情判断是**两次独立的小调用**——
不想花就切「台词 → 只用本地」。

### 时段播报：每次开始会话告诉你现在是高峰还是空闲（`src/client/22-pricing.js`）

按 [DeepSeek 开放平台价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 的规则，
**每次你开口（以及打开页面）时**让球报一次当前时段与价格：

语气会随时段和你当前在不在干活变（有语气库，不是一句模板复制粘贴）：

> 高峰时段咯——输入 2（元每百万 tokens）、输出 8，钱包在滴血。还有 2 小时恢复空闲价。
>
> 半夜最划算——空闲价，输入 1（元每百万 tokens）、输出 4，只有高峰的一半。到明天 9:00 前都是空闲时段。
>
> 周末整天空闲价：输入 1（元每百万 tokens）、输出 4，高峰要 2、8。整个周末都是空闲时段。

- **规则**：北京时间周一至周五 **9:00–12:00、14:00–18:00** 为高峰，其余时段（含周末与节假日全天）
  为空闲；**空闲价 = 高峰价的一半**。
- **价格表放在宿主半**（`lib/index.js` 的 `PRICING`）：`deepseek-flash` 与 `deepseek-v4-pro` 两档，
  按当前会话的模型自动选；调价只改一处。价格拿不到时用客户端兜底表。
- **这句话不走模型**：内容必须准、也不能花 token，所以是本地拼好直接上屏（用「专注」表情说）。
- **不会刷屏**：同一时段 30 分钟内只报一次；时段切换（或你换会话）会立刻重报。
- **节假日**：中国法定节假日无法离线判断，所以面板给了「自动 / 按高峰 / 按空闲」三档手动校准，
  切换后立刻重报一次。

### 拟人化：心跳、动作、视线（`src/client/24-life.js`）

引擎自带的待机小动作（`antics`）只在「没有被显式指定表情」时才会自己触发，所以一旦被切成「思考中」就停住了。插件自己实现了一层「生命循环」，让它看起来像活的：

**① 不规则心跳**（不是等间隔的机械节拍）

- 多数是轻拍：3.2–9.5 秒；
- 约 22% 概率来个连拍：1.8–3.2 秒两下（像深呼吸）；
- 每 7 拍停久一点：15–21 秒发呆。

**② 动作库**（每次参数随机，可轻可重）

| 动作 | 权重 | 效果 |
| --- | --- | --- |
| `work` | 3/10 | 换工作表情：`32 处理中` / `40 检索资料` / `31 接收任务` / `37 复述回忆` |
| `flash` | 1/10 | 闪一下情绪 1.6–2.6 秒：`13 惊讶` / `16 专注` / `14 害羞` |
| `eager` | 1/10 | 「我来我来」：`07 抖动唤醒` / `19 满意` / `33 任务完成`，0.9–1.5 秒后回去 |
| `shy` | 1/10 | 害羞 `14` 一秒多 |
| `gaze` | 1/10 | 自己瞟一眼输入框或别处，0.7–1.4 秒后看回来 |
| `bounce` | 1/10 | 弹跳，35% 概率连弹两下 |
| `spin` | 1/10 | 自旋（25% 概率转两圈，甩出更长的彩带） |
| `burst` | 1/10 | 撒花（30% 概率撒一大把） |

**③ 视线会「看人」**

- **你在输入框里敲字时**，它扭头看向输入框看一眼（1.1 秒），停手 2.5 秒后看回鼠标；
- 垂直方向做了「只往下看」的压缩——输入框总在球下方，对称换算会让眼睛往上翻，看起来像在看天花板；
- 没人理它时，`gaze` 动作会自己瞟一眼。

**④ 情绪弧线**：任务跑完的瞬间会先给一个「松一口气」的表情（`19 满意` / `10 开心` / `33 任务完成`）+ 一次弹跳，1.4 秒后再交回给大脑判断的心情或待机。

整层都可以用面板「小动作 → 安静工作」关掉。

### AI 心情（表情球的“大脑”）

一轮对话结束（会话 `running` 从 true 落到 false）时触发一次：

```
用户最后一句 + 助手最后一段（各截断）
        ↓  /float-ball-rpc/float-ball/mood
宿主动态取 ctx.llm + agentDefaultModel.currentSelection()（或面板里指定的 provider/model）
        ↓  模型只回两行：ID <两位编号> / WHY <15 字内理由>
表情球切到该表情（不写进你的配置，下一轮再判断）
```

- **模型跟随**：大脑固定使用**当前会话正在用的模型**（读 dsh 客户端共享的 `modelDirectories`，也就是聊天输入框上方那个模型）。用户中途换模型，球也跟着换；取不到时才回退到 dsh 的默认 Agent 模型。面板里只读展示，不需要配置。
- **触发时机**（面板「心情 → 时机」）：
  - `每轮任务`（默认）—— 整个任务跑完判断一次；
  - `每条回复` —— 每收到一条助手回复判断一次，**最快 20 秒一次**（同一会话节流）。
- **成本**：`maxTokens: 256`（给推理型模型留思考空间），无后台轮询。

### 实测 token 开销

用你机器上配置的真实模型（deepseek-v4-flash）实测四次不同长度的对话（输入已按 360/480 字符截断，32 个表情名的白名单一起发）：

| 场景 | 输入 | 输出 | 合计 |
| --- | --- | --- | --- |
| 短（「太棒了！」） | 354 | 14 | **368** |
| 典型（报 bug + 一段修复说明） | 391 | 126 | **517** |
| 长（接近截断上限） | 622 | 126 | **748** |
| 辱骂类 | 369 | 82 | **451** |

平均 **≈520 tokens/次**。

- 默认 `每轮任务`：跑 30 分钟的任务、中间有 6 个 bug 7 次鼓励 —— **整轮只调用 1 次**，≈520 tokens。
- 切到 `每条回复`：13 个来回最多 13 次（还受 20 秒节流），≈6.8k tokens。
- 对比：一次普通 agent 工具调用（读文件 + 推理）通常就是 10k–50k tokens。所以这个功能是「一次工具调用的零头」量级；按主流 API 价格折算约 **¥0.002/次**，13 次约 **¥0.02**（具体单价取决于你在 `settings.yaml` 里配的那个 provider）。
- 它是**独立的一次性分类调用**（只有 system prompt + 两段截断文本，不带工具、不带会话历史、不进缓存），不是开一个 Agent 去读会话 —— 后者每次要几万 token。
- **失败降级**：模型没返回合法 ID、没配 API Key、`llm` 服务缺失——都只是让球回到默认表情，并在面板上显示原因（`上次心情` 那一行会变成错误文案）。
- **不需要 / 不想花 token**：面板「心情」里点「不用大脑」，或者把「时机」切回「每轮任务」。

事件来源：`ctx.sessions.binding(current).eventSource` 的事件窗口，只倒着扫最近 240 条、取最后一条 `user/message` 与 `assistant/message`。

### 任务状态联动（“有意识”的部分）

| 会话状态 | 表情 | 说明 |
| --- | --- | --- |
| `running: true`（正在跑任务） | `30` 思考中 | 眼睛上翻 + 头顶光环环绕 |
| `running: false`（空闲） | `02` 待机放空 | 左右张望、偶尔自旋 |

实现方式：订阅客户端共享的会话列表快照（`ctx.sessions.list`，每个会话行带 `running` 位），
取**当前选中的会话**，没有选中时退化为“有没有任何会话在跑”。这个自动表情只作为临时
`mood` 叠加，**不会写进你的配置**——你手选的表情始终保留，任务结束就回到它。
不想要这个行为就在面板里点「只用手选的」。

常用表情对照（完整 32 种见引擎文档）：

| 场景 | emotionId | 表情 |
| --- | --- | --- |
| 空闲待机 | `02` | 待机放空 |
| 无操作太久 | `00` | 睡眠（zzz） |
| 任务完成 | `33` | 笑眼 + 撒花 |
| 思考 / 推理中 | `30` | 眼睛上翻 + 光环 |
| 出错 | `34` | 圆睁 + 脸色闪动 |
| 正在检索资料 | `40` | 左右扫读 |

```
src/client/15-style.js       样式（.dfb-* 命名空间，注入单个 <style>）
src/client/20-ball.js        悬浮球：引擎挂载、注视、拖动（rAF 合并的 DOM 直写）、手势、快捷键
src/client/25-brain.js       AI 大脑：读最近一对消息、触发分类调用、写入心情
src/client/18-speech.js      聊天气泡：本地台词库、说话节流、模型台词请求
src/client/30-panel.js       表情面板：分组表情、尺寸、主题、行为开关
src/client/90-main.js        引导、Portal、槽位注册（shell.overlay + sidebar.footer.action）
src/vendor/grok-ball.engine.js  Grok Ball 引擎（原样内置，MIT，见 LICENSE.grok-ball）
build-client.mjs             把上面几块拼成 lib/client.js
cordis.patch.yml             profile patch：把插件行插入 web 花名册
```

### 它是怎么接进 dsh 的

- **宿主半**（`lib/index.js`）只注册一个 Connection RPC 通道 `/float-ball-rpc`（独立通道，不占用其他插件共享的 `/rpc`）。
- **浏览器半**（`lib/client.js`）是一个 `window.__ModuleLoader__` 工厂，`require("react")` 拿到外壳提供的 React；`apply(ctx)` 里声明 `inject = ["slots", "connection", "sessions"]`（槽位、宿主 RPC、会话运行状态）。
- 悬浮球本体在 `document.body` 上自建 `fixed` 容器（`#dsh-float-ball-root`），所以不会被布局容器裁剪；`shell.overlay` 只占一个座位（渲染 `null`），`sidebar.footer.action` 提供设置入口。
- 引擎以独立模块注册进客户端模块表（`<包名>/engine/grok-ball`），主工厂 `require` 它，避免把 12 万字符的数据层再复制一份。
- **降级**：宿主 RPC 不可用时（通道没挂载 / 请求失败 / 超时），配置与位置自动落到 `localStorage`，功能完整，只是少了跨浏览器共享的配置文件。

## 🛠️ 开发

```sh
node build-client.mjs          # 重新生成 lib/client.js（纯 node，无需 pnpm）
node --check lib/client.js     # 语法自检
```

改动 `src/client/*.js` 后必须重新 `node build-client.mjs`：浏览器只会加载 `lib/client.js`。

`pnpm run dev:web` 的客户端 HMR 只对**已装载**的插件行生效；新增插件、改 `lib/index.js` 或 `cordis.patch.yml` 都必须重启 `dsh web`。

## ⚠️ 已知限制 / 后续可做

- 时段判定按「工作日 + 两个高峰窗口」计算，**识别不了中国法定节假日**（需要联网日历）；
  面板里可以手动切「按空闲」校准。

- 模型偶尔仍会把提示词里的示例粘出来（实测 8 次里出现过 1 次形如「比如：『…』」）。
  现在两侧各有一道闸门拦它并重说，但正文残片仍可能漏过；遇到就点「不说话」或切「只用本地」。

- 引擎是非 React 的 DOM/SVG 实现，挂载在 React 管理的容器**内部**（`useEffect` 里创建），React 不参与其内部渲染。若将来把它换成真正的 React 组件，需要重写 `20-ball.js` 的挂载部分。
- 「任务状态」目前只区分「跑 / 不跑」两态（`30 思考中` / `02 待机`）。要做「正在检索 → `40`、出错 → `34`」这种细分，需要继续读工具调用与错误事件。
- AI 心情默认只在**一轮任务结束时**判断一次；要更灵敏就在面板里把「时机」切成「每条回复」（受 20 秒节流）。两者都不是逐 token 实时变化。
- 面板里暂未做颜色自定义（引擎支持任意 `color` / `eyeColor`，见 `Util.themeColors`）。
- 仍在使用 `ReactDOM.render`（React 18 的 legacy 入口）。换成 `createRoot` 需要在 `package.json` 的 `dsh.client.external` 里声明 `react-dom` 才能 `require("react-dom/client")`，暂未改动。

## 🔌 作为 dsh Web 社区插件

本仓库按 dsh 社区客户端插件的通用形态组织，可以直接被别人 `dsh plugin add` 安装：

| 约定 | 本仓库的做法 |
| --- | --- |
| `package.json` 的 `dsh.bundle.patch` | 指向 `cordis.patch.yml`，安装后自动把插件行插入 web 花名册 |
| `package.json` 的 `dsh.client` | `platform: "web"` + `inject` 官方客户端包；`./client` 导出预构建 bundle |
| 宿主半 | `lib/index.js`，只用 node 内建模块，零运行依赖 |
| 浏览器半 | `lib/client.js`，一个 `window.__ModuleLoader__` 工厂，`apply(ctx)` 里 `inject = ["slots","connection","sessions"]` |
| 占用的槽位 | `shell.overlay`（悬浮球本体）、`sidebar.footer.action`（设置入口） |
| 占用的 RPC 通道 | 独立的 `/float-ball-rpc`（不抢其他插件共享的 `/rpc`） |
| 许可证 | MIT（引擎 MIT，带原始 `LICENSE.grok-ball`） |
